Population Pup privacy policy

Last updated 11 October 2026

Population Pup is a math game for children. It is built so that there is nothing to collect.

The Android and Fire tablet app

  • The app collects no personal information of any kind.
  • It has no accounts, no sign-in, no advertising, no analytics and no in-app purchases.
  • It requests no device permissions and makes no internet connections. It works fully offline.
  • Game progress (the pup's name, math progress and what has been built) is saved only on the device, inside the app. It is never sent anywhere. Removing the app deletes it.

The web version

The same game can be played in a web browser. It also has no accounts, advertising or analytics, and saves progress only in that browser's own storage on your device. The web page loads its two typefaces from Google Fonts, so your browser contacts Google's font servers when the page opens, as it does on any site that uses Google Fonts. The page is hosted on GitHub Pages, which may keep standard server logs.

Children

Population Pup is intended for children and families. Because it collects no personal information from anyone, it collects none from children.

Changes

If this policy changes, the new version will be posted on this page with a new date.
