Population Pup privacy policy

Last updated 11 October 2026

Population Pup is a math and English game for children. It is built so that there is nothing to collect. One optional feature, off unless a grown-up turns it on, sends a typed sentence out for marking; it is described below.

The Android and Fire tablet app

  • The app collects no personal information of any kind.
  • It has no accounts, no sign-in, no advertising, no analytics and no in-app purchases.
  • It works fully offline and, as installed, makes no internet connections. Its only permission is internet access, which is used solely by the optional writing coach described below.
  • Game progress (the pup's name, math progress and what has been built), together with a log of play for the grown-up report (time spent, which parts of the game were used, and the answer to "Was today fun?"), is saved only on the device, inside the app. It is never sent anywhere. Removing the app deletes it.

The optional writing coach

Now and then the game asks the child to type one sentence of their own. By default that sentence is marked on the device and goes nowhere.

A grown-up can choose to add their own Anthropic API key behind the grown-up code. Only then, each typed sentence is sent over the internet to Anthropic's Claude service, together with the writing question it answers, so that it can be marked and a line of feedback returned. No name, account, device identifier or game progress is sent, and the developer of this game never receives the sentence or the key. The key is stored only on the device. Anthropic handles the request under its own terms and privacy policy for API customers. Removing the key in the same place turns the feature off.

The web version

The same game can be played in a web browser. It also has no accounts, advertising or analytics, and saves progress only in that browser's own storage on your device. The web page loads its two typefaces from Google Fonts, so your browser contacts Google's font servers when the page opens, as it does on any site that uses Google Fonts. The page is hosted on GitHub Pages, which may keep standard server logs.

Children

Population Pup is intended for children and families. The game itself collects no personal information from anyone, including children. If a grown-up turns on the optional writing coach, the sentences a child types are sent to Anthropic as described above, so a grown-up should decide whether that is right for their child.

Changes

If this policy changes, the new version will be posted on this page with a new date.
